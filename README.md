# Palindrome Test

PHP 8.1+ сервис для проверки строк на палиндром с полной поддержкой UTF-8 и гибкой нормализацией.

## 🎯 Возможности

- ✅ Полная поддержка UTF-8 (кириллица, латиница, диакритика)
- ✅ Гибкая нормализация через enum-опции
- ✅ Строгая типизация (`strict_types`, `enum`, `match`)
- ✅ Защита от edge cases (пустые строки, спецсимволы, длинные строки)
- ✅ Готовый набор тест-кейсов

## 📋 Требования

- PHP 8.1 или выше
- Расширение `mbstring`

Проверка окружения:

```bash
php -v              # Должна быть версия 8.1+
php -m | grep mbstring  # Должно вывести: mbstring
```

## 🚀 Запуск

```bash
php palindrome.php
```

Ожидаемый вывод:

```
✅ [0] Простой палиндром (кириллица)
✅ [1] Не палиндром
✅ [2] Пустая строка

```

## 💡 Использование

### Базовый пример

```php
$checker = new PalindromeChecker();

// Простая проверка
$checker->isPalindrome('казак'); // true
$checker->isPalindrome('привет'); // false

// С нормализацией
$checker->isPalindrome(
    'А роза упала на лапу Азора',
    [PalindromeOption::IGNORE_CASE, PalindromeOption::IGNORE_SPACES]
); // true
```

### Доступные опции

| Опция | Описание | Пример |
|---|---|---|
| `IGNORE_CASE` | Игнорировать регистр | `Казак` → `казак` |
| `IGNORE_SPACES` | Игнорировать пробелы | `а роза` → `ароза` |
| `IGNORE_PUNCTUATION` | Игнорировать пунктуацию | `A man, a plan` → `A man a plan` |
| `IGNORE_NON_ALNUM` | Оставить только буквы и цифры | `A man, a plan!` → `Amanaplan` |

Опции комбинируются и применяются в фиксированном приоритетном порядке.

## 🏗 Архитектура

```
PalindromeChecker
├── isPalindrome()          # Публичный API
├── normalize()             # Нормализация строки по опциям
├── reverseUtf8()           # Безопасный реверс UTF-8
├── validateOptions()       # Валидация входных данных
└── sortOptions()           # Приоритизация опций
```

### Ключевые решения

1. **Enum вместо констант** — типобезопасность, автокомплит в IDE, защита от опечаток.
2. **`match` вместо `switch`** — строгая проверка exhaustiveness в PHP 8.
3. **Приоритизация опций** — избегаем конфликтов (например, пробел — это и space, и punctuation).
4. **`preg_split('//u')` вместо `strrev()`** — `strrev()` ломает многобайтовые символы.
5. **`final` класс** — запрещение наследования, так как класс не предназначен для расширения.

## 🧪 Тест-кейсы

Проект включает 14 тест-кейсов, покрывающих:

- Базовые случаи (кириллица, латиница, цифры)
- Edge cases (пустая строка, один символ, только пробелы)
- Нормализацию (регистр, пробелы, пунктуация)
- UTF-8 (кириллица, смешанные алфавиты)
- Производительность (строка из 10 000 символов)
